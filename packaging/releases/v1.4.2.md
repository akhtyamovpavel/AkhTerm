## Bug Fixes in AkhTerm v1.4.2

- **Fix Stale Tab-Age Working Timer in Existing Tabs ([#95](https://github.com/akhtyamovpavel/AkhTerm/issues/95)):**
  - Exposed `PaneRegistry::live_turn_secs` outside `#[cfg(test)]` and updated `TermSession::live_turn_secs` (`src/terminal/session.rs`) to read the active turn duration from `pane_registry` instead of falling back to tab-creation `TermSession::work_started`.
  - Launching a new agent session (such as `AGY`, `Claude Code`, or `Codex`) inside a tab opened hours earlier now counts from the start of the active turn (`0s`, `5s`, ...) instead of jumping immediately to the total age of the tab (`8h 58m`).
  - Required an active `work_started_at` timestamp in both `PaneRecord::live_turn_secs` and the non-registry fallback of `TermSession::live_turn_secs`, with regression tests in `src/terminal/pane_registry.rs` and `src/telemetry/pane_radar.rs`.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.4.2-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.4.2-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.4.2_linux_x86_64.tar.gz
install -m 0755 akhterm-1.4.2-linux-x86_64/akhterm ~/.local/bin/akhterm
```
