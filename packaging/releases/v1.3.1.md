## What's new in AkhTerm 1.3.1

- **Read agent context through the active SSH route.** Background telemetry uses the original OpenSSH client's connection settings, including supported custom ports, config files and jump hosts. Connections that share an alias but use different routes are queried separately.
- **Follow the foreground agent in tmux.** The probe checks the foreground process group inside the selected pane. A shell title no longer hides an active agent's context. When the shell takes back the terminal, the prior reading clears.
- **See token details without clipped rows.** The Tokens menu grows with its contents and scrolls for longer lists. The active pane appears first when it has a reading or turn timer. Panes with only timing data show no fabricated token counts.
