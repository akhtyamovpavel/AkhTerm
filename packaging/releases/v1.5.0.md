## What's New in AkhTerm v1.5.0

- **Deterministic Git Checkpoints per Agent Turn ("Undo Last Agent Turn", [#101](https://github.com/akhtyamovpavel/AkhTerm/issues/101)):**
  - Lightweight per-pane snapshots stored under `refs/akhterm/checkpoints/<pane>/<ts>` via non-mutating `git stash create` and an isolated temporary index for untracked files (`src/swarm/git_checkpoints.rs`), leaving `HEAD`, active branch, `.git/index`, and `refs/stash` completely untouched during capture.
  - Debounced auto-capture on agent `Working` / `PreToolUse` hooks, newest-first listing with `git diff --stat` inside `Git ▾`, automatic pruning beyond 20 checkpoints per pane, and 1-click Undo with a pre-undo safety checkpoint and Command Palette entries.
- **OSC 133 Command Navigation & 1-Click "Send Failed Output to Agent" ([#102](https://github.com/akhtyamovpavel/AkhTerm/issues/102)):**
  - Added `src/terminal/cmd_marks.rs` with a 128-entry per-pane ring buffer tracking OSC 133 `A`/`B`/`C`/`D;exit_code` prompts and command boundaries.
  - Jump between command prompts with `Ctrl+Shift+Up` / `Ctrl+Shift+Down`, copy the last command's output, or send failed output (`exit != 0`) directly to an agent pane as a safe nested-fence Markdown block from the VTE right-click context menu or Command Palette (`Ctrl+K` remains untouched for Antigravity Approve and terminal apps).
- **Context Rot Thresholds & 1-Click Agent Handoff Pack ([#103](https://github.com/akhtyamovpavel/AkhTerm/issues/103)):**
  - Visual context-health thresholds (`>= 70%` Warning, `>= 85%` Critical, and prompt-cache drop alerts) across the topbar tokens pill, tokens popover, and sidebar in both Dark and Light Zinc themes (`src/swarm/agent_handoff.rs`).
  - 1-click "Hand Off to Agent" (`Claude`, `Codex`, `AGY`) inside the Tokens popover and Command Palette: builds a compact structured Markdown Handoff Pack (branch, `git diff --stat`, recent terminal tail, active `.md` brief) with atomic `0600` staging + clipboard copy and launches the target agent in a fresh tab.
- **1-Click Official Agent Hooks Installer ([#104](https://github.com/akhtyamovpavel/AkhTerm/issues/104)):**
  - Added `src/app/hook_installer.rs` and a dedicated Agent Hooks section in Settings (`src/ui/hooks_section.rs`) + Command Palette to inspect, install, and uninstall official `akhterm-ctl notify` hooks for **Claude Code** (`~/.claude/settings.json`), **Codex CLI** (`~/.codex/config.toml`), and **AGY CLI** with idempotent merges preserving all existing user hooks and atomic `0600` / `0700` writes.
- **Git Worktree Manager ([#105](https://github.com/akhtyamovpavel/AkhTerm/issues/105)):**
  - Added `src/swarm/worktree_mgr.rs` and `src/swarm/worktree_ui.rs` inside `Git ▾` and Command Palette: inspect all worktrees (branch, dirty/clean, merged status), create a new branch worktree with optional immediate agent launch (`Shell`, `Claude`, `Codex`, `AGY`), jump to any worktree in 1 click, and safely prune clean merged worktrees without touching primary or dirty worktrees.
- **Unified RU/EN Localization, Popover Sizing Audit & Resilient SSH Tunnels ([#106](https://github.com/akhtyamovpavel/AkhTerm/issues/106)):**
  - Completed a full bilingual RU/EN sweep across `tokens_ui`, `sidebar`, `tab_strip`, `topbar`, and `swarm_view` with consistent `UiLocale::Auto` resolution and zero mixed-language leakage, plus a natural-height propagation audit across every popover `GtkScrolledWindow`.
  - Managed SSH tunnels (`src/sys/ssh_tunnel.rs`, `src/sys/pinned_tunnels.rs`, `src/ui/ports_ui.rs`) now transition cleanly to `Disconnected` on unexpected drop instead of disappearing, support 1-click `Reconnect`, and persist pinned tunnels atomically (`0600` in XDG state) with 1-click `Restore Pinned`.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.5.0-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.5.0-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.5.0_linux_x86_64.tar.gz
install -m 0755 akhterm-1.5.0-linux-x86_64/akhterm ~/.local/bin/akhterm
```
