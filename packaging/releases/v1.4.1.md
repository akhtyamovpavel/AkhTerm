## Bug Fixes in AkhTerm v1.4.1

- **Free `Ctrl+K` for Antigravity Approve & Terminal Apps ([#92](https://github.com/akhtyamovpavel/AkhTerm/issues/92)):**
  - Removed the `Ctrl+K` (and Cyrillic `Ctrl+Л`, keycode 45) alias from Command Palette shortcut interception (`src/ui/palette.rs`) so `Ctrl+K` passes directly through to child terminal applications such as Antigravity (`Approve`), `bash`/`zsh` (`kill-line`), and `tmux`.
  - **Command Palette** remains bound to `Ctrl+Shift+P` (Latin, Cyrillic `З`, and keycode 33).

## Architecture & Maintainability

- **Zero Grade C Modules Across All 102 `src/**/*.rs` Files ([#86](https://github.com/akhtyamovpavel/AkhTerm/issues/86), [#87](https://github.com/akhtyamovpavel/AkhTerm/issues/87), [#88](https://github.com/akhtyamovpavel/AkhTerm/issues/88)):**
  - Eliminated all 11 remaining Grade C files across `src/telemetry/` and `src/ui/` (including `telemetry/mi.rs` from `MI 48.80` / `CC 8` up to `MI 62.67` / `CC 2` with zero scoring-formula drift), separated GTK clipboard/image paste into `src/terminal/clipboard_paste.rs`, and extracted POSIX probe helpers into `src/telemetry/agent_probe.sh`.
  - Decomposed the `2175 SLOC` `src/telemetry/telemetry.rs` monolith into `telemetry.rs` (`905 SLOC`), `jsonl_parse.rs`, `tokens_ui.rs`, and `telemetry_tests.rs`, and enforced a repository-wide zero-Grade-C Maintainability Index gate (`MI >= 58.0`) in `cargo test`.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.4.1-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.4.1-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.4.1_linux_x86_64.tar.gz
install -m 0755 akhterm-1.4.1-linux-x86_64/akhterm ~/.local/bin/akhterm
```
