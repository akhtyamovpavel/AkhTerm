## What's new in AkhTerm 1.2.0

- **Read and copy Markdown beside your terminal.** Right-click a local Markdown path and choose **Open alongside**. Search with `Ctrl+F`, copy a fenced code block, or paste selected text into the active terminal. [#65](https://github.com/akhtyamovpavel/AkhTerm/pull/65)
- **See context and cache usage for the focused pane.** Switching SSH connections or tmux panes clears the previous pane's reading. When the agent reports cache counters, the percentage shows how much of the latest request's input came from the prompt cache. [#66](https://github.com/akhtyamovpavel/AkhTerm/pull/66)
- **Launch OpenCode from the Agents menu.** AkhTerm includes an OpenCode TUI plugin that reports usage for the displayed session. For remote OpenCode or a custom `OPENCODE_TUI_CONFIG`, see the plugin setup in the [README](https://github.com/akhtyamovpavel/AkhTerm/blob/v1.2.0/README.md#per-pane-radar-telemetry--ptyosc-bridge).
- **Return to a clean tab after exiting an agent.** The agent name and activity indicator clear when the shell regains control, including after `Ctrl+D`. [#69](https://github.com/akhtyamovpavel/AkhTerm/pull/69)
- **Follow the Maintainability Index after `cd`.** The MI button shows when a calculation is pending. Open it to see which directory is being analyzed. Local tmux sessions use the focused pane's directory, and scans with no eligible source files have their own status. [#70](https://github.com/akhtyamovpavel/AkhTerm/pull/70)
