## Highlights in AkhTerm v1.1.0

- **In-App Self-Updater & Floating Update Card ([#61](https://github.com/akhtyamovpavel/AkhTerm/issues/61)):**
  - **Floating GTK 3 Update Card:** Non-intrusive overlay card (`Available`, `Downloading`, `Verifying`, `ReadyToRestart`, `SystemPackageHint`, `Failed`) in Dark/Light Zinc with live **RU / EN** localization, **"What's new"** release link, **"Dismiss"** per-version suppression, and one-click **"Restart now"** preserving session layout (`tabs-v2`).
  - **`SHA-256`-Verified Hybrid Delivery:** Checks GitHub Releases (`15 s` after startup and every `6 h`, or manually from **About** and Command Palette **"Check for Updates"**), verifies downloaded archives against `SHA256SUMS`, atomically replaces user-writable installs (`~/.local/bin/akhterm`) via portable `.tar.gz`, and guides system `/usr/bin/akhterm` installs to the matching `.deb` / `.rpm` package.
- **Hold-and-Drag Tab Reordering & Collapsible Project Folders ([#55](https://github.com/akhtyamovpavel/AkhTerm/issues/55), [#56](https://github.com/akhtyamovpavel/AkhTerm/issues/56)):**
  - Drag tabs smoothly (`6 px` threshold, zero click-focus jitter) in both the top tab strip and the vertical sidebar.
  - OpenAI-style collapsible project folders in the sidebar automatically group local tabs by repository root (merging linked `git worktree` checkouts under their primary repository) with a `+` action to open a new shell directly in that folder.
- **Pane-Bounded Mouse Selection & Copy in Split `tmux` Panes ([#57](https://github.com/akhtyamovpavel/AkhTerm/issues/57)):**
  - Detects split `tmux` pane geometries locally and over `SSH`, clamps mouse drag selection strictly inside the active `tmux` pane with a Cairo highlight overlay, and copies only that pane's text to the clipboard without bleeding across vertical dividers or adjacent `tmux` windows.
- **Live `~/.ssh/config` Reload & Accurate `tmux` Window Token Accounting ([#58](https://github.com/akhtyamovpavel/AkhTerm/issues/58), [#60](https://github.com/akhtyamovpavel/AkhTerm/issues/60), [#54](https://github.com/akhtyamovpavel/AkhTerm/issues/54)):**
  - Automatically reloads `~/.ssh/config` and `Include` globs whenever their modification timestamps change, updating `Профили / SSH` and Command Palette entries live without a restart.
  - Immediately recounts per-tab and window-wide `input · cache · output` tokens when switching active `tmux` windows.
  - Prevents child process arguments or subtools mentioning another agent name (for example `claude` inside a command line) from overriding the parent agent (`AGY`, `Codex`, `Claude Code`) in tab and sidebar status badges.
- **Component-Oriented `src/` Architecture ([#59](https://github.com/akhtyamovpavel/AkhTerm/issues/59), [#48](https://github.com/akhtyamovpavel/AkhTerm/issues/48)):**
  - Reorganized the flat `src/` tree into seven domain modules (`app/`, `sys/`, `terminal/`, `workspace/`, `telemetry/`, `swarm/`, `ui/`) with zero external Cargo crates and full Maintainability Index (`MI`) gate coverage.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.1.0-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.1.0-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.1.0_linux_x86_64.tar.gz
install -m 0755 akhterm-1.1.0-linux-x86_64/akhterm ~/.local/bin/akhterm
```
