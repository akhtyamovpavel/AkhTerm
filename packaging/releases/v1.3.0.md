## What's new in AkhTerm 1.3.0

- **Read Markdown from an SSH pane.** Right-click a Markdown path and choose **Open alongside**. The preview remembers the host and directory of the pane you clicked, even when you switch tabs. Use **Refresh** after an agent edits the file. If the remote directory is unknown, enter the absolute path.
- **Quote a passage in an agent prompt.** Select text in the preview, choose the recipient and click **Insert quote**. AkhTerm includes the path, line numbers and, for remote files, the host. You can edit the draft before pressing Enter. Remote agents such as OpenCode can receive quotes inside tmux.

SSH previews require noninteractive authentication and a known host key. The reader accepts UTF-8 Markdown up to 2 MiB. To insert a quote into a remote agent, its tmux pane must report the AkhTerm 1.3 title format. [SSH and Markdown changes](https://github.com/akhtyamovpavel/AkhTerm/pull/72)
