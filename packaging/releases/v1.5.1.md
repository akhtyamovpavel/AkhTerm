## Bug Fixes in AkhTerm v1.5.1

- **Detect Antigravity CLI (`agy`) Approval Prompts (`Yes`, `Yes and save`, `No`) Across Multi-Line TUI Footers ([#114](https://github.com/akhtyamovpavel/AkhTerm/issues/114)):**
  - Added `agy` and agent approval choice patterns (`"yes and save"`, `"yes, and save"`, `"yes, always"`, `"yes and always"`, `"yes, and don't ask"`, `"yes, for this session"`, `"always allow"`, `"allow this command"`, `"approve once"`, `"approve always"`, `"requires approval"`, `"needs approval"`) to `src/telemetry/approval.rs`.
  - Added a dedicated TUI approval-menu matcher (`TUI_MENU_PROMPT_LINES = 12`) so vertical, numbered, horizontal, and marked binary `Yes` / `No` approval menus remain accurately detected as `NeedsApproval` ("Ждёт апрува" / "Needs approval") instead of `Ready` ("Готово") even when keybind hints and status bars sit below the dialog, while keeping the 6-line scrolled-prompt guard intact for ordinary output.
  - Preferred extracting the prompt question line above the options as the approval tooltip snippet.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.5.1-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.5.1-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.5.1_linux_x86_64.tar.gz
install -m 0755 akhterm-1.5.1-linux-x86_64/akhterm ~/.local/bin/akhterm
```
