## Highlights in AkhTerm v1.4.0

- **Interactive Local & SSH Diff Review Panel ([#76](https://github.com/akhtyamovpavel/AkhTerm/issues/76)):**
  - **Side-by-Side Diff & Hunk Actions:** Open from `Git ▾` (**Review Diff**), Command Palette, or `Ctrl+Shift+B` to inspect local working-tree, staged, and branch (`merge-base..HEAD`) changes as well as non-interactive `SSH` diffs (with a `2 MiB` safety cap), per-file **Reviewed** checkboxes, Cyrillic/C-quoted path unescaping, and local single-hunk **Stage hunk** / **Revert hunk** actions in Dark and Light Zinc.
  - **Inline Review Comments Batched to Agent:** Select lines or navigate hunks (`▲` / `▼`), queue multiple inline comments, and deliver the formatted Markdown review batch directly into the target local, `SSH`, or `tmux` coding agent prompt.
- **Local Unix Socket Control Plane, CLI API & Official Agent Hooks ([#77](https://github.com/akhtyamovpavel/AkhTerm/issues/77)):**
  - **Private IPC Socket & CLI Commands:** Each window listens on a private Unix domain socket (`0600`, cleaned up on exit) and exports `AKHTERM_SOCKET` and `AKHTERM_PANE_ID` into every pane. Script workflows with `akhterm status [--json]`, `focus`, `notify`, `send`, `open-doc`, and `hooks install` (plus the `ctl` alias) with zero external Cargo crates.
  - **Authoritative Agent Hooks & Clickable Notifications:** Idempotent installers for Claude Code and Codex CLI report live hook states across pane headers, sidebar, and Swarm Dashboard with automatic TTL and exit cleanup, while clickable desktop notifications (`notify-send --action=focus`) jump directly to the source pane.
- **Live Port Radar & 1-Click Managed SSH Port Forwarding ([#78](https://github.com/akhtyamovpavel/AkhTerm/issues/78)):**
  - **Local & Remote Listener Discovery:** Reads Linux `/proc/net/tcp{,6}` scoped to each local tab's process tree and probes listening ports on active `SSH` sessions, presenting them live inside the `Ports ▾` popover and Command Palette.
  - **Automatic `ssh -N -L` Tunnels & `Ctrl+Click` Forwarding:** Launch or stop collision-free local port forwards in one click from `Ports ▾`, or `Ctrl+Click` any remote `localhost:<port>` link to forward and open it automatically, with full tunnel cleanup when the tab or window closes.
- **System Resource & Battery Wattage Monitor ([#79](https://github.com/akhtyamovpavel/AkhTerm/issues/79)):**
  - **Zero-Process Live Status Bar Widget & Popover:** Samples `/proc/stat`, `/proc/loadavg`, `/proc/meminfo`, `/proc/<pid>/status`, and `/sys/class/power_supply/BAT*` every `1.8 s` directly in Rust to display host `CPU` utilization, `RAM` / `Swap` plus focused-tab process-tree `RSS`, and laptop battery `%`, wattage (`W`), `ETA`, and health in a compact bilingual **RU / EN** Dark/Light Zinc pill and popover (gracefully omitting battery telemetry on desktops).
- **Feature-Branching Git Workflow Policy ([#75](https://github.com/akhtyamovpavel/AkhTerm/issues/75)):**
  - Documented the issue-first feature-branch and Pull Request workflow (`feature/<id>-<slug>`, `fix/<id>-<slug>`, `release/vX.Y.Z`) alongside SemVer patch releases and Maintainability Index (`MI >= 60.0`) quality gates in `AGENTS.md`.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.4.0-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.4.0-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.4.0_linux_x86_64.tar.gz
install -m 0755 akhterm-1.4.0-linux-x86_64/akhterm ~/.local/bin/akhterm
```
