## Bug Fixes in AkhTerm v1.4.3

- **Expand `Ports ▾` Popover Height Naturally ([#98](https://github.com/akhtyamovpavel/AkhTerm/issues/98)):**
  - Enabled `gtk_scrolled_window_set_propagate_natural_height(scroll, 1)` in `make_ports_scroll` (`src/ui/ports_ui.rs`) so the `Ports` popover expands naturally up to `340 px` to display all detected port rows and action buttons (`Open`, `Copy`, `Forward & Open`, `Stop`) instead of collapsing into a narrow scrollbar slit.
- **Filter OS Ephemeral & Client Ports from Port Radar ([#98](https://github.com/akhtyamovpavel/AkhTerm/issues/98)):**
  - Added `/proc/sys/net/ipv4/ip_local_port_range` detection (default `32768..=60999`) plus IANA dynamic port filtering (`49152..=65535`) in `src/telemetry/port_radar.rs`.
  - Random kernel-assigned `bind(0)` internal sockets from CLI agents, LSPs, and IPC helpers (such as `:33849`) no longer clutter the `Ports` badge or popover on local and remote tabs, while real dev servers (`:3000`, `:5173`, `:8000`, `:11434`, etc.), SSH tunnel readiness checks, and explicitly printed `localhost:<port>` terminal URLs keep working as expected.

## Installation

### Ubuntu 24.04 & 26.04 (`amd64`)

```sh
sudo apt install ./akhterm_1.4.3-1_amd64.deb
```

### Fedora 41 & 42 (`x86_64`)

```sh
sudo dnf install ./akhterm-1.4.3-1.x86_64.rpm
```

### Portable Linux Tarball (`x86_64`, supports one-click in-app self-update)

```sh
tar -xzf akhterm_1.4.3_linux_x86_64.tar.gz
install -m 0755 akhterm-1.4.3-linux-x86_64/akhterm ~/.local/bin/akhterm
```
